# Insurance Cost Predictor

This project contains a simple Flask application that uses a linear regression model trained from the provided insurance dataset to estimate insurance costs from a form.

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

Open http://localhost:8000

## Deploy on Vercel

1. Push this folder to GitHub.
2. Import it in Vercel.
3. Vercel will use the configuration in vercel.json.
